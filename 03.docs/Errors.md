# Frequent Errors


## Error1 : "*sh: expo: command not found*"

- Cause : expo is not installed or system path is not identified.

- Solution : install the necessery software
- Command : run ``npm i``

## CommandError: xcrun is not configured correctly. Ensure `sudo xcode-select --reset` works before running this command again.
 
 - Cause : in mac-os X-code may not have been installed properly.
 - Solution : reset the x-code-select
 - Command : `sudo xcode-select --reset`
 - Caution : you are using super admin previlage to run
